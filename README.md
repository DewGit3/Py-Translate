# Py translator
### The translator is written in Python and supports 48 languages!

## How does it work?
When you start the utility, you are prompted to select the  
language you need and enter its key; it is written next to the language.  
  
example:  
english - eng

## Regarding the development:
Since the project is open‑source, you can freely take the code and edit it,  
fix any bugs I’ve made, and generally do whatever you like with the code.  


## The project is divided into 3 different files:  
- main - The main file that launches the entire project.  
- main_page - A file that stores the entire program interface and the list of languages.  
- lang - A file that processes user actions.
